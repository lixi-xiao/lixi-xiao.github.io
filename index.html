安全不是附加功能

从数据层到运维层，每一环都内置安全设计。这不是插件能补的，是从架构开始的。

✓

CSRF Token 验证

所有表单提交和 API 请求强制携带 CSRF Token，服务端验证，防跨站请求伪造。

✓

安全会话管理

HttpOnly + SameSite=Strict + Secure，PHPSESSID 配置完整，防会话劫持。

✓

环境指纹 (Canvas + FNV-1a)

浏览器环境指纹生成，识别异常客户端，辅助反欺诈和追踪。

✓

哈希链审计日志

操作日志以哈希链串联，防篡改。任何删除或篡改可被检测。

✓

Python 守护进程

inotify 文件完整性实时监控（1115 行），异常即告警，7×24 运行。

✓

蜜罐同步

ym-hfish-sync.py 蜜罐数据同步，主动收集攻击者信息。

✓

SSRF 防护

isPrivateHost 检测 + 域名白名单，防服务端请求伪造攻击。

✓

出站限速

音乐 API 出站请求 60 秒 40 次/IP，防滥用和资源耗尽。

一分钟上线

一键安装脚本，无需宝塔面板，无需 Composer，无需 npm build。

1

下载

克隆仓库或下载 Release 压缩包。

git clone https://github.com/lixi-xiao/you-super-markdown.git
2

安装

运行一键安装脚本，自动完成所有配置。

sudo bash ym-install.sh
3

访问

打开浏览器，进入后台，开始上传文档。

your-domain.com/sc.php
